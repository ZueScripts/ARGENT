# ARGENT – ATM Simulator

ARGENT is a multi-page ATM simulator built with HTML, CSS, and JavaScript. The project simulates basic ATM operations through a simple, interactive user interface.

This project was developed as a hands-on way to practise frontend development, JavaScript logic, DOM manipulation, and browser storage.

## Features

- **Account Setup:** Create an account using a full name and a four-digit PIN.
- **PIN Verification:** Verify account details before accessing the ATM menu.
- **Balance Inquiry:** View your current account balance.
- **Cash Deposit:** Deposit money and update your account balance.
- **Cash Withdrawal:** Withdraw money with insufficient-funds validation.
- **Change PIN:** Change your existing PIN with validation.
- **Account Details:** View account information, including account number, account type, balance, and status.
- **Data Persistence:** Account information and balance are stored using browser localStorage.

## Technologies Used

- HTML5 – Page structure and content.
- CSS3 – Styling, layouts, and glassmorphism effects.
- JavaScript – Functionality, validation, DOM manipulation, and application logic.
- Git & GitHub – Version control and project hosting.

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/ZueScripts/ARGENT.git
   ```
2. Open the project folder in VS Code.
3. Open `atm.html` in your browser, preferably using Live Server.
4. Create an account and explore the ATM features.

## Important Note

ARGENT is an educational simulation project. It does not connect to real banking systems or process real financial transactions. PINs and account information are stored in browser localStorage for demonstration purposes and are not secured for real-world banking use.
